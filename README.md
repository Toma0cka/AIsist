# 🤖 Jarvis Hub — Локальный ИИ-Ассистент

**Jarvis Hub** — это высокотехнологичный голосовой помощник для Windows, работающий локально. Он объединяет офлайн-распознавание речи, мощь локальных LLM-моделей (через Ollama) и стильный графический интерфейс для управления компьютером.

## 🌟 Ключевые возможности

* 🎙 **Офлайн-распознавание речи:** Использует библиотеку Vosk для быстрого и безопасного перевода голоса в текст без интернета.
* 🧠 **Интеллект на базе LLM:** Подключен к локальной нейросети через Ollama (в примере используется `qwen2.5:3b`), что позволяет вести осмысленные диалоги и получать саркастичные ответы в стиле Тони Старка.
* 🖥 **Современный UI (PyQt6):** Удобная панель управления с историей диалогов, настройками аудио-устройств и плавающим виджетом, который всегда поверх окон.
* ⚡ **Пользовательские команды:** Добавляйте свои фразы-триггеры и пути к программам (.exe) или сайтам прямо через графический интерфейс без редактирования кода. 
* 📱 **Telegram-модуль:** Управляйте компьютером удаленно через собственного Telegram-бота.
* 🔊 **Контроль системы:** Управление громкостью, переключение треков, перевод ПК в спящий режим и парсинг свежих новостей.

---

## 🛠 Технологический стек

* **Python 3.10+**
* **PyQt6** (Графический интерфейс)
* **Vosk** (Speech-to-Text)
* **Edge-TTS** (Text-to-Speech)
* **Ollama** (Локальный LLM-сервер)
* **Sounddevice / PyAudio** (Работа с аудиоустройствами)
* **PyInstaller** (Сборка в исполняемый файл)

## 🚀 Установка и запуск (Для разработчиков)

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python. Клонируйте репозиторий и установите зависимости:
```bash
git clone [https://github.com/ВАШ_НИК/JarvisProject.git](https://github.com/ВАШ_НИК/JarvisProject.git)
cd JarvisProject
pip install PyQt6 vosk sounddevice telebot rapidfuzz keyboard edge-tts

2. Установка модели распознавания речи

    Скачайте русскую языковую модель с официального сайта Vosk.

    Распакуйте скачанный архив.

    Переименуйте папку с моделью в model и поместите её в корень проекта (рядом с gui.py).

3. Настройка локального интеллекта (Ollama)

    Установите Ollama.

    Скачайте нужную модель через терминал (в коде используется qwen2.5:3b):

Bash

ollama run qwen2.5:3b

4. Запуск

Запустите главный файл интерфейса:
Bash

python gui.py

📦 Сборка в .exe (Standalone версия)

Чтобы превратить скрипт в полноценную программу, не требующую установленного Python:

    Установите упаковщик:

Bash

pip install pyinstaller

    Скомпилируйте проект (флаг --collect-all обязателен для корректной работы скрытых зависимостей Vosk):

Bash

pyinstaller --noconsole --name "Jarvis" --collect-all vosk gui.py

    После завершения сборки зайдите в папку dist/Jarvis.

    Важно: Вручную скопируйте папку model и файл config.json в папку dist/Jarvis (рядом с Jarvis.exe).

    Готово! Запускайте Jarvis.exe.

⚙️ Настройка и использование
Добавление своих команд

Откройте интерфейс (кнопка ⚙ Настройки) и добавьте команду в таблицу.
Вы можете указывать сразу несколько фраз через запятую.

    Пример команды: открой фотошоп, запусти фотошоп, дизайн

    Пример пути: C:/Program Files/Adobe/Photoshop.exe

Telegram-бот

Для активации удаленного управления вставьте ваш токен бота от BotFather и ваш личный Telegram ID в переменные TELEGRAM_BOT_TOKEN и TELEGRAM_ALLOWED_ID внутри файла brain.py. Бот будет принимать команды только от указанного ID.
Файл конфигурации (config.json)

Все настройки громкости, выбранных микрофонов, динамиков и пользовательских путей автоматически сохраняются в этот файл при нажатии кнопки "Сохранить" в интерфейсе. Не удаляйте его.
