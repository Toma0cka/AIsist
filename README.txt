# 🤖 Проект "Джарвис" - Локальный ИИ-ассистент

Привет! Это твой личный ИИ-дворецкий. Он работает полностью локально (без интернета), управляет компьютером голосом, включает музыку, парсит свежие новости и общается с тобой с помощью сарказма и нейросетей. 

Никаких сложных программ вроде VS Code не нужно. Просто следуй инструкции ниже.

## 🛠️ Шаг 1: Установка базовых программ
1. **Python:** Скачай [Python 3.10+](https://www.python.org/downloads/). 
   * ⚠️ **ОЧЕНЬ ВАЖНО:** При установке в самом первом окне обязательно поставь галочку **«Add Python to PATH»** (Добавить в PATH) внизу экрана! Без этого ничего не сработает.
2. **Ollama (Мозг Джарвиса):** Скачай и установи [Ollama](https://ollama.com/). Это программа, которая крутит нейросети прямо на твоей видеокарте.

## 🧠 Шаг 2: Загрузка нейросети
1. Нажми `Win + R`, введи `cmd` и нажми Enter (откроется черное окно).
2. Скопируй и вставь туда команду: `ollama run qwen2.5:3b`
3. Дождись скачивания (около 2 ГБ). Когда появится поле для ввода сообщения, можешь закрыть это черное окно. Ollama теперь работает в фоне.

## ⚙️ Шаг 3: Настройка Джарвиса
1. Скачай этот проект (зеленая кнопка **Code -> Download ZIP** вверху страницы) и распакуй папку в любое удобное место (например, в Документы).
2. Зайди в папку и запусти файл **`install.bat`** (просто кликни дважды). Он сам скачает и установит нужные библиотеки. Дождись надписи "Установка завершена".
3. Нажми правой кнопкой мыши по файлу **`brain.py`** -> Открыть с помощью -> **Блокнот**.
   * Найди команду запуска Дискорда (нажми `Ctrl+F` и введи `discord`). Замени путь `C:\Users\...\Discord.exe` на свой путь к Дискорду.
   * Найди команду протокола дом (`welcome_home`). В строке `os.startfile("spotify:track:...")` можешь вставить ссылку на свой любимый трек.
   * Сохрани файл (`Ctrl+S`) и закрой Блокнот.

## 🚀 Шаг 4: Как запустить и добавить в автозагрузку
Чтобы Джарвис работал всегда и без надоедливых черных окон:
1. В папке с проектом найди файл **`jarvis_start.vbs`**.
2. Нажми по нему правой кнопкой мыши -> **Создать ярлык**.
3. Нажми `Win + R`, введи `shell:startup` и нажми Enter. Откроется папка автозагрузки Windows.
4. Перетащи созданный **ярлык** в эту папку.

**Готово!** Теперь при каждом включении ПК Джарвис будет просыпаться вместе с тобой. 

*P.S. Чтобы запустить его прямо сейчас без перезагрузки, просто дважды кликни по файлу `jarvis_start.vbs`.*

## 🗣️ Список основных команд:
* "Джарвис, что по новостям" — ИИ соберет заголовки и расскажет сводку.
* "Джарвис, я дома" — Протокол "Дом" (включит музыку, стим, дискорд и поприветствует тебя).
* "Джарвис, какая погода / погода на завтра" — Метеосводка.
* "Джарвис, включи на ютубе [название]" — Поиск видео.
* Любые свободные фразы — Джарвис поддержит разговор, опираясь на локальную нейросеть.
